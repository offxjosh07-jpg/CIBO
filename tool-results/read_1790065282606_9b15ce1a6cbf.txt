     9→## Architecture Decision
    10→- Single user-facing route `/` (sandbox constraint). Client-side view switching via Zustand store (`useAppView`).
    11→- API routes under `/api/*` for backend (route handlers).
    12→- Prisma + SQLite (sandbox constraint — user requested PostgreSQL but environment supports SQLite only).
    13→- Custom JWT auth in httpOnly cookies (bcrypt password hashing).
    14→- CIBO brand: forest green / cream / gold / orange palette. Custom SVG logo + mascot.

    36→- Created 37 new route.ts files plus a shared _lib/helpers.ts module under src/app/api/.
    37→- All routes use the @/lib/api helpers (requireUser, requireRole, ok, err, parseJson, rateLimit, haversineKm, discountPct, etc.) and @/lib/auth (hashPassword, verifyPassword, createSession, destroySession, generateOtp, generateOrderNumber).
    38→- Every dynamic route awaits `params` (Next.js 16 Promise semantics).
    39→- JSON string DB fields (images, allergens, evidence, notification.data) are deserialized to arrays/objects on read and re-serialized on write via the _lib/helpers.ts utils.
    40→- passwordHash is never returned in any response — every User row is funneled through `toPublicUser`/`toPublicUserOrNull`.
    41→- db.$transaction used for: order creation (inventory decrement + order + orderItems + payment + provider/customer totals + notifications), order cancellation (inventory restore + status + payment refund + counter rollback + notifications), listing creation (+ safety report), favorites toggle (via unique constraint), review creation (+ provider rating recompute), address default-mgmt, provider-signup (+ documents), admin verify/suspend/takedown/complaint-resolve (+ AdminAction + Notification).
    42→- Rate limiting applied on auth endpoints (login 20/min, signup 10/min, provider-signup 8/min) keyed by client IP from x-forwarded-for.
    43→- Bug fixed during smoke test: login route's dummy hash for missing users was misformatted ("deadbeef:deadbeef"), causing crypto.timingSafeEqual to throw RangeError. Now uses a properly-sized dummy hash (32-hex-char salt + 128-hex-char hash) so timing attack mitigation still works.
